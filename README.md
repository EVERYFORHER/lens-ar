# LENS AR

4차시 위산과 제산제 AR 모듈. 주소: https://everyforher.github.io/lens-ar/

- 학생: 공통 엔진 홈 카드의 [수업 활동]으로 열림 (`?sid=&name=&subject=&cls=&lesson=`이 붙음).
- 엔진 차시 탭 외부링크: `https://everyforher.github.io/lens-ar/?k=<AR_KEY>` (화학 4차시, 통합과학 1차시).
- 인쇄 카드: `assets/cards/cards_ED_A4.pdf` (몸 카드 E는 A5, 알약 카드 D는 A6). 인식 대상 `cardED.mind` (`tools/compile.html?cards=ED`).
- `test/` 카드 인식 테스트 (후보 A·B·C), `tools/compile.html?cards=C` 로 .mind 생성.
- `lib/` MindAR 1.2.5, three.js 0.160.0 (각 폴더의 LICENSE).
